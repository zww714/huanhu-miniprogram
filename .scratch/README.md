# Local Agent Workspace

Agent-generated PRDs, issues, triage notes, and temporary planning documents live here.

Recommended structure:

```text
.scratch/
└─ <feature-slug>/
   ├─ PRD.md
   └─ issues/
      ├─ 01-first-task.md
      └─ 02-second-task.md
```

These files are local markdown records for collaboration with Codex skills. They do not replace WeChat Code Management commits or branches.
