# 换乎 ZJU版 UI Redesign Design Tokens

本规范用于新版首页、发现页、消息页、我的页的高还原重构。当前阶段只沉淀视觉规则和基础组件，不直接替换主页面。

## 1. 颜色规范

| Token | 色值 | 用途 |
| --- | --- | --- |
| Primary Blue | `#2563EB` | 主按钮、选中态、强调图标、关键数字 |
| Primary Light | `#EAF2FF` | 蓝色浅背景、选中卡片背景、弱提示 |
| Page Background | `#F6F8FC` | 页面浅灰蓝背景 |
| Card Background | `#FFFFFF` | 卡片、列表行、弹层主体 |
| Text Primary | `#0F172A` | 页面标题、卡片标题、主信息 |
| Text Secondary | `#475569` | 正文、学校学院信息、描述 |
| Text Tertiary | `#94A3B8` | 时间、辅助信息、占位文字 |
| Border | `#E2E8F0` | 搜索框、卡片分割线、按钮描边 |
| Success | `#16A34A` | 已认证、进行中、成功状态 |
| Warning | `#F97316` | 热门、高匹配、警示标签 |
| Danger | `#EF4444` | 未读角标、删除、危险操作 |
| Tag Background | `#F1F5F9` | 默认标签底色 |

## 2. 字号规范

项目主样式使用 `rpx`。后续四个主页面应优先使用以下字号层级：

| Token | 字号 | 用途 |
| --- | --- | --- |
| 页面标题 | `34rpx` | 顶部标题：首页、发现、消息、我的 |
| 品牌标题 | `40rpx` | 首页品牌“换乎” |
| 一级 Tab | `28rpx` | 技能交换 / 兴趣搭子 / 社区活动 |
| 模块标题 | `32rpx` | 今日推荐、本周校园热门话题 |
| 卡片标题 | `30rpx` | 用户名、帖子标题、活动标题 |
| 正文 | `26rpx` | 简介、帖子摘要、消息预览 |
| 辅助信息 | `24rpx` | 学院、时间、地点、统计 |
| 标签文字 | `22rpx` | Chip、状态标签 |
| 按钮文字 | `26rpx` | 联系TA、报名、编辑资料 |
| 强调数字 | `40rpx` | 匹配度、评分、统计数字 |

## 3. 圆角规范

| Token | 圆角 | 用途 |
| --- | --- | --- |
| radiusXs | `8rpx` | 小图标、局部状态块 |
| radiusSm | `12rpx` | 小标签、局部封面角 |
| radiusMd | `18rpx` | 搜索框、普通按钮 |
| radiusLg | `24rpx` | 普通卡片、筛选 Chip |
| radiusXl | `32rpx` | Banner、大个人卡片、消息面板 |
| radiusPill | `999rpx` | 胶囊按钮、头像、浮动按钮 |

## 4. 间距规范

| Token | 间距 | 用途 |
| --- | --- | --- |
| pagePaddingX | `32rpx` | 页面左右边距 |
| sectionGap | `24rpx` | 模块上下间距 |
| cardPadding | `28rpx` | 大卡片内边距 |
| cardGap | `20rpx` | 卡片之间间距 |
| itemGap | `16rpx` | 列表项内部间距 |
| tagGap | `12rpx` | 标签之间间距 |
| floatingRight | `32rpx` | 悬浮发布按钮右边距 |
| floatingBottom | `160rpx` | 悬浮发布按钮距离底部 |
| tabBarSafePadding | `32rpx` | tabBar 上方内容安全距离 |

普通页面底部不应叠加大块空白，只保留自然安全区：`24rpx + env(safe-area-inset-bottom)`。有悬浮按钮页面只给列表底部留出按钮活动空间。

## 6. 组件规范

### 搜索框

- 高度约 `72rpx`
- 圆角 `radiusPill`
- 白色背景，浅边框，轻阴影
- 左侧搜索图标，placeholder 使用 `textTertiary`
- 首页 placeholder：搜索技能、搭子、活动或帖子
- 发现页 placeholder：搜索帖子、技能、活动或同学

### 一级文字 Tab

- 三等分或横向均分
- 选中态：主色文字 + 短下划线
- 未选中：灰蓝色文字
- 高度控制在 `76rpx - 84rpx`

### 横向筛选 Chip

- 高度 `52rpx - 60rpx`
- 选中：蓝底白字
- 默认：浅灰底深色字
- 横向滚动，不压缩文字

### 内容卡片

- 白色背景
- 圆角 `radiusLg` 或 `radiusXl`
- 内边距 `cardPadding`
- 轻阴影 + 浅边框
- 卡片间距 `cardGap`

### 用户卡片

- 头像、昵称、认证、学院年级校区、简介、标签、匹配度、联系按钮
- 姓名突出，辅助信息弱化
- 标签最多一到两行，超出用 `+N`
- 联系按钮不能被悬浮按钮遮挡

### 帖子卡片

- 发现页采用左图右文或上文下作者结构
- 标题 1-2 行，摘要 2 行以内
- 标签、作者信息、点赞评论收藏统一在底部

### 活动卡片

- 封面图 + 状态标签
- 时间、地点、报名人数清晰展示
- 主按钮使用蓝色胶囊

### 消息入口卡片

- 图标块大圆角
- 红点角标放在图标右上角
- 标题居中
- 未读数字不遮挡主体

### 列表行

- 头像圆形
- 主标题加粗
- 副标题弱色
- 时间或状态放右侧
- 行之间使用浅分割线

### 悬浮发布按钮

- 蓝色圆形按钮
- 白色加号
- 默认由页面控制定位
- 不直接覆盖 tabBar，不遮挡主要操作按钮

### 底部 TabBar 红点

- 未读使用红色角标
- 数字超过 99 显示 `99+`
- 没有未读时隐藏

### 空状态

- 文案自然，不出现开发说明
- 页面保持留白但不产生底部大块空白
- 可以配轻量图标或浅蓝插画占位

### 加载状态

- 优先使用骨架屏或轻量 loading
- 云函数失败时显示 mock fallback 或自然空状态，不白屏
